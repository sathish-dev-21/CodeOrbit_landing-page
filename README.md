# FlowTask — Responsive Landing Page

A fully responsive landing page for **FlowTask**, a productivity and task management SaaS product concept. Built as an internship project task to demonstrate responsive design using CSS Flexbox/Grid, navigation, hero banners, and interactive UI elements.

## 📋 Project Overview
This landing page was built to satisfy the following internship task requirements:
- Design a responsive landing page using CSS Flexbox or Grid
- Include a navigation bar, hero banner, and call-to-action button
- Add simple hover effects and transitions for interactivity
- Test responsiveness across at least three screen sizes

## ✨ Features
- **Sticky navigation bar** with logo, nav links, CTA button, and a functional mobile hamburger menu
- **Hero section** with headline, subheadline, primary and secondary CTA buttons
- **Features section** — 3-column grid of feature cards with hover lift + shadow transition
- **Call-to-action band** with a centered signup prompt
- **Footer** with copyright and social icon placeholders
- **Fully responsive** across Desktop (1024px+), Tablet (768–1024px), and Mobile (<768px) breakpoints
- **Smooth hover transitions** on all buttons and interactive elements

## 🛠️ Tech Stack
- HTML5 (semantic markup)
- CSS3 (Flexbox for nav/CTA sections, Grid for feature cards, CSS custom properties for theming)
- Vanilla JavaScript (mobile menu toggle)
- Google Fonts (Inter/Poppins)

## 📱 Responsiveness Testing
Tested across the following breakpoints:
| Device Type | Screen Width | Layout Behavior |
|---|---|---|
| Desktop | > 1024px | Full nav bar, 3-column feature grid |
| Tablet | 768px – 1024px | Condensed nav, 2-column feature grid |
| Mobile | < 768px | Hamburger menu, single-column stacked layout |
